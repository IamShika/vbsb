# Comes with :
• Cool dynamic animations (color swap, Score up, basically almost everything is animated.)\
• A lots of customisation (colors, Team names, Banners, Fonts, Scale of fonts, Icon all for free!!)\
• Timer counter (Counts time after the match begin or even in intermission!)\
• Intermission Banner (For displaying messages like program name, what's up today etc.)\
• Timeout Banner (Big score and sets display for viewer to see while the timer counts)\
• Optimized for smaller devices without cutting any animations!

All connected together by Cloudflare workers.\
And hosted by Github Pages. Many thanks to these companies!\
